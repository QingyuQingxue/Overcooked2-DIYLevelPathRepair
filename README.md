# Overcooked2-DIYLevelPathRepair
修复胡闹厨房2 因自制图文件夹名称错误导致的问题 / Fixed issues in Overcooked! 2 caused by an incorrect folder name in the DIYLevel folder


## 说明
部分地图改名后可能会导致游玩有问题，该Mod的目标就是解决该类问题。


## 验证版本

**GUA——DIYLevel**: 0.10.0

**OC2DIYLevelRuntimeWLoader(通用前置)**: 3.10.2


## 已验证地图

1、pourtoi(foryou)：已修复改名后左上角大铁锅消失的问题；

2、Nanami_XQY：已修复改名后搅拌和蒸锅的时间修改不生效的问题；

3、zhuzi 0.13版本：已修复该版本下改名后下方大铁锅消失的问题，该问题只出现在0.13版本，后续版本已修复。
